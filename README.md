# CricPulse 🏏

A modern cricket live score and match analytics web application.

## Live Demo
[View CricPulse](https://cricpulse-score.onrender.com)

## Tech Stack
- React.js
- Vite
- JavaScript
- Axios
- CSS
- Cricbuzz Cricket API (RapidAPI)

## Features
- Live cricket scores
- Upcoming and recent matches
- Match details and scorecards
- Team and match information
- Responsive user interface
